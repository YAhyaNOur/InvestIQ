#  DICTIONNAIRE DES VARIABLES FINANCIÈRES

### LIQUIDITÉ ET DETTE
Total Cash (M) : trésorerie disponible (cash en millions $)
===============================================================

Total Debt (M) : dette totale de l’entreprise (en millions $)
===============================================================

Debt To Equity : ratio dette / capitaux propres
=> mesure le niveau d’endettement
faible dette → 0
forte dette → 1
===============================================================

Current Ratio : actifs court terme / dettes court terme
=> mesure la capacité à payer les dettes à court terme
===============================================================

Quick Ratio : version plus stricte du Current Ratio
=> exclut les stocks (liquidité immédiate)
===============================================================





###  VALORISATION
PE Ratio : Price / Earnings
=> valorisation par rapport aux bénéfices***************(flag)
normal → 0
trop élevé → 1
===============================================================
PB Ratio : Price / Book
=> valeur marché / valeur comptable
===============================================================
PS Ratio : Price / Sales
=> valeur marché / chiffre d’affaires
===============================================================
EV/EBITDA : valeur entreprise / EBITDA
=> mesure la valorisation globale vs performance opérationnelle
===============================================================
EV/Revenue : valeur entreprise / revenu
=> mesure combien le marché paie par rapport au chiffre d’affaires
===============================================================



### RENTABILITÉ ET RISQUE
ROE (Return on Equity) : rentabilité des capitaux propres
=> Profit / Equity
===============================================================
ROA (Return on Assets) : rentabilité des actifs
=> Profit / Total Assets
===============================================================
Beta : mesure du risque (volatilité vs marché)
=> >1 = plus risqué que le marché
=> <1 = plus stable
===============================================================



### CIBLES ET STATUTS
Valuation (M USD) : valeur estimée de l’entreprise (en millions $)
===============================================================
Profitable : indique si l’entreprise est rentable (0 = non, 1 = oui)
===============================================================
Exit Status : statut de sortie de l’entreprise
(ex: IPO, Acquisition, Closed)
===============================================================
